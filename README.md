# DevOps Engineer Portfolio (Next.js)

A responsive, dark-themed portfolio starter built with the Next.js App Router, TypeScript and CSS.

## Run locally

1. Install Node.js (current LTS).
2. Extract this project and open the folder in a terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open http://localhost:3000.

To create a production build:

```bash
npm run build
npm start
```

## Personalise before publishing

Search and replace these placeholders in `app/page.tsx`:

- `your.email@example.com` — add your professional email.
- `DevOps Engineer` — add your preferred display name or professional title.
- Update project descriptions with your actual responsibilities, tools and verified results.
- Add LinkedIn and GitHub links if you want them displayed.
- Remove any tool or skill you have not used professionally.

## Important project-content note

The project cards are representative summaries based on the supplied profile context. They are not claims of independently verified project outcomes. Add accurate metrics only when you can substantiate them (for example, deployment duration reduced, release frequency, number of services, or failure-rate improvement).

## Deploy

This project can be deployed to Vercel or any platform that supports Next.js. Connect the repository, select the project root, and use the default Next.js build settings.
